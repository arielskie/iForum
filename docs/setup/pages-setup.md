# Essential Pages & Legal Templates

Your iForum package comes with pre-written, professionally styled HTML templates located in the `Pages` folder.

---

## 📄 Included Pages

1. **Community Guidelines (`Community Guidelines.txt`)**
   - Rules of conduct, anti-spam policies, respectful debate expectations, and moderation guidelines.
2. **Help Center (`Help Center.txt`)**
   - Knowledge base and FAQ on how to start threads, earn badges, format code with Markdown, and recover accounts.
3. **Privacy Policy (`Privacy Policy.txt`)**
   - Standard GDPR/CCPA compliant privacy declaration covering Firebase Google Auth and local storage caching.
4. **Terms of Service (`Terms of Service.txt`)**
   - Intellectual property disclaimers, user content liability, and site usage conditions.

---

## 🛠️ How to Publish These in Blogger

1. In your **Blogger Dashboard**, navigate to **Pages**.
2. Click **+ New Page**.
3. Set the Title (e.g., `Community Guidelines`).
4. In the editor toolbar, switch from **Compose view** (`<pencil>`) to **HTML view** (`</>`).
5. Open the respective `.txt` file from the `Pages` directory, copy all HTML content, and paste it.
6. Click **Publish**.
7. Copy the published page URL and add it to your header or footer menu in **Layout → Header Menu / Footer Links**.
